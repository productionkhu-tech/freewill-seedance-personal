# Freewill Seedance Personal

본인 API 키로 쓰는 시댄스(Seedance) 영상 생성 앱 — Windows 용 개인판입니다.

## 내려받기

[**Releases**](../../releases/latest) 에서 `Freewill-Seedance-Personal-Setup-<버전>.exe` 를 받아 설치하세요.
설치한 뒤에는 앱을 켤 때마다 새 판을 확인해 자동으로 업데이트합니다.

## 처음 켜면 — 내 키 넣기

설정 패널 맨 위 **내 키** › 키 넣기 에서 넣습니다. 넣은 키는 앱이 한 번 확인한 뒤 **이 PC 에만, Windows 계정으로 암호화해** 저장합니다.
요금은 각 서비스의 **본인 계정**으로 청구됩니다.

| 키 | 필요 | 어디서 |
|---|---|---|
| **BytePlus** (시댄스) | 필수 | BytePlus 콘솔 › ModelArk › API Key. Seedance 모델을 먼저 켜 두세요(Activate). |
| **Cloudflare R2** | 선택 — 레퍼런스용 | 아래 'R2 만드는 법'. 없으면 텍스트 → 영상만 됩니다. |
| **Google Gemini** | 선택 — 옴니용 | Google AI Studio › API Key |

### R2 만드는 법 (레퍼런스 이미지 · 영상 · 오디오를 쓸 때)

BytePlus 가 레퍼런스 파일을 가져갈 수 있게 잠깐 올려 두는 곳입니다. 생성이 끝나면 앱이 지웁니다.

1. Cloudflare 에 가입하고 대시보드에서 **R2 Object Storage** 를 켭니다. 결제 수단 등록이 필요하지만, 이 앱 사용량은 무료 구간(저장 10GB · 내려받기 무료) 안입니다.
2. **버킷**을 만들고, 그 버킷의 설정 › 객체 수명 주기 규칙에 **'1일 뒤 삭제'** 를 추가합니다.
3. R2 › **API 토큰 관리** › 토큰 만들기 — 권한 **객체 읽기 및 쓰기**, 범위 **그 버킷만**.
4. 나오는 **액세스 키 ID · 비밀 액세스 키 · S3 엔드포인트**와 버킷 이름을 앱의 내 키 › R2 네 칸에 붙여 넣고 '확인하고 저장'. 앱이 작은 파일을 올렸다 지워 보며 확인합니다.

## 알아 둘 것

- **만든 영상은 이 PC 에 남습니다.** BytePlus 가 주는 영상 주소는 24시간 뒤 사라지므로, '생성 시 자동 다운로드' 가 기본으로 켜져 있습니다.
- 작업 기록 백업: `문서\Freewill Seedance Personal Backup`
- 넣은 키는 업데이트해도 그대로 남습니다. 다른 PC · 다른 Windows 계정에서는 다시 넣어야 합니다(암호화가 이 계정에 묶여 있습니다).
